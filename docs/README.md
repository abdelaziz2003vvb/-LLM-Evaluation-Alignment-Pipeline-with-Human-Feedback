# llm-eval-pipeline

This repository is an end-to-end autonomous evaluation and alignment pipeline for LLMs with human feedback.

Contents
- `configs/` - configuration files
- `src/` - core modules: evaluation, feedback, alignment, dashboards, pipeline
- `examples/complete_example.py` - runnable example orchestration

See `GETTING_STARTED.md` to run locally and `DEVELOPMENT.md` for contribution notes.
